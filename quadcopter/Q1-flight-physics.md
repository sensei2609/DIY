## 1. Introduction to Quadcopter Dynamics

### 1.1 What Makes a Quadcopter Fly?

A quadcopter (also called quadrotor) has:
- **4 motors** arranged in a square/X configuration
- **4 propellers** - two spin clockwise (CW), two counter-clockwise (CCW)
- **One rigid body** (the frame)
- **6 degrees of freedom**: 3 translational (x, y, z) + 3 rotational (roll, pitch, yaw)

**Key Principle:** By varying the speeds of the four motors independently, we can control all 6 degrees of freedom.

### 1.2 Why Four Rotors?

## 2. The Four Forces

### 2.1 Thrust (T)

**Generated by propellers pushing air downward.**

```
T_total = T1 + T2 + T3 + T4
```

Thrust from a single propeller (simplified):

```
T = C_T × ρ × n² × D⁴

Where:
C_T = thrust coefficient (depends on prop design)
ρ = air density (kg/m³)
n = rotational speed (rev/s)
D = propeller diameter (m)
```

**More practical relationship:**

```
T ≈ k_T × ω²

Where:
k_T = thrust coefficient (includes all factors)
ω = angular velocity (rad/s)
```

```python
# Calculate thrust from motor speed
def thrust_from_rpm(rpm, k_t):
    """
    Calculate thrust from motor RPM
    k_t: thrust coefficient (N/(rad/s)²)
    """
    omega = rpm * 2 * np.pi / 60  # Convert to rad/s
    thrust = k_t * omega**2
    return thrust

# Example: 10-inch props on 1000kV motors
# Typical k_t ≈ 1e-6 N/(rad/s)²

k_t = 1e-6
rpm_range = np.linspace(0, 10000, 100)
thrusts = thrust_from_rpm(rpm_range, k_t)

plt.figure(figsize=(10, 6))
plt.plot(rpm_range, thrusts)
plt.xlabel('Motor RPM')
plt.ylabel('Thrust (N)')
plt.title('Thrust vs Motor Speed')
plt.grid(True)
plt.savefig('thrust_vs_rpm.png')

T_hover_total = m_quad * 9.81

# Find RPM needed

```

**Important:** Thrust-to-weight ratio > 2:1 is good for acrobatic flight!

### 2.2 Weight (W)

```
W = m × g = 1.5 kg × 9.81 m/s² = 14.7 N  (downward)
```

Simple, but varies with:

### 2.3 Drag (D)

Air resistance opposing motion:

```
D = ½ρv²C_d A
```

### 2.4 Lift (L)

**Wait - doesn't the thrust provide lift?**

Yes! For a quadcopter, "lift" and "thrust" are the same thing. Unlike airplanes with wings, quadcopters generate lift entirely through thrust.

## 3. Motor Configuration and Control

### 3.1 Motor Numbering Convention

**X-Configuration (most common):**

```
      FRONT
        ↑
   M3    M1
    ⊙CCW  ⊗CW
        ╬
    ⊗CW  ⊙CCW
   M4    M2

⊗ = Clockwise (CW)
⊙ = Counter-Clockwise (CCW)
```

### 3.2 Control Mixing

How do we control 6 DOF with 4 motors?

**Hover (all equal):**
```python
T1 = T2 = T3 = T4 = T_hover/4
```

**Throttle (vertical motion):**
```
Increase all motors equally
ΔT_throttle = [+ΔT, +ΔT, +ΔT, +ΔT]
```

**Roll (rotation about X-axis):**
```
Right side spins faster than left
ΔT_roll = [+ΔT, -ΔT, -ΔT, +ΔT]
  M1,M4 increase → roll right
  M2,M3 decrease
```

**Pitch (rotation about Y-axis):**
```
Front spins faster than back
ΔT_pitch = [+ΔT, +ΔT, -ΔT, -ΔT]
  M1,M3 increase → pitch forward
  M2,M4 decrease
```

**Yaw (rotation about Z-axis):**
```
CW motors speed up, CCW slow down
ΔT_yaw = [+ΔT, -ΔT, +ΔT, -ΔT]
  M1,M4 (CW) increase → yaw right
  M2,M3 (CCW) decrease
```

**Implementation:**

```python
def motor_mixing(throttle, roll, pitch, yaw):
    """
    Calculate individual motor thrusts from control inputs
    All inputs in range [-1, 1] except throttle [0, 1]
    Returns motor commands [M1, M2, M3, M4]
    """
    # Base thrust from throttle
    base = throttle

    # X-configuration mixing matrix
    M1 = base + roll - pitch + yaw  # Front-Right (CW)
    M2 = base - roll + pitch - yaw  # Back-Left (CW)
    M3 = base - roll - pitch + yaw  # Front-Left (CCW)
    M4 = base + roll + pitch - yaw  # Back-Right (CCW)

    # Constrain to [0, 1]
    motors = np.array([M1, M2, M3, M4])
    motors = np.clip(motors, 0, 1)

    return motors
```

## 4. Coordinate Systems

### 4.1 Body Frame vs Earth Frame

**Earth Frame (Inertial/NED):**
- Fixed to the ground
- X = North, Y = East, Z = Down (NED convention)
- Or: X = Forward, Y = Right, Z = Down (local NED)

**Body Frame:**
- Fixed to the quadcopter
- X = Forward (nose direction)
- Y = Right wing
- Z = Down (through center)
- Rotates with the quadcopter

### 4.2 Coordinate Transformation

**From body to earth:**
```
v_earth = R(φ,θ,ψ) × v_body
```

**From earth to body:**
```
v_body = R⁻¹(φ,θ,ψ) × v_earth = Rᵀ(φ,θ,ψ) × v_earth
```

```python
def body_to_earth(v_body, roll, pitch, yaw):
    """Transform vector from body frame to earth frame"""
    cr, sr = np.cos(roll), np.sin(roll)
    cp, sp = np.cos(pitch), np.sin(pitch)
    cy, sy = np.cos(yaw), np.sin(yaw)

    R = np.array([
        [cy*cp, cy*sp*sr - sy*cr, cy*sp*cr + sy*sr],
        [sy*cp, sy*sp*sr + cy*cr, sy*sp*cr - cy*sr],
        [-sp, cp*sr, cp*cr]
    ])

    return R @ v_body

def earth_to_body(v_earth, roll, pitch, yaw):
    """Transform vector from earth frame to body frame"""
    return body_to_earth(v_earth, -yaw, -pitch, -roll).T @ v_earth

# Example: Thrust vector in body frame
thrust_body = np.array([0, 0, -15])  # 15N upward in body frame

# Quadcopter tilted: 10° roll, 20° pitch
roll = np.radians(10)
pitch = np.radians(20)
yaw = np.radians(0)

thrust_earth = body_to_earth(thrust_body, roll, pitch, yaw)

print("Thrust in body frame:", thrust_body)
print("Thrust in earth frame:", thrust_earth)
print(f"\nHorizontal component: {np.sqrt(thrust_earth[0]**2 + thrust_earth[1]**2):.2f} N")
print(f"Vertical component: {thrust_earth[2]:.2f} N")

# This is how the quadcopter moves horizontally!
```

## 5. Equations of Motion

### 5.1 Translational Motion (Newton's Second Law)

**In Earth Frame:**
```
m × a_earth = F_total_earth

F_total = F_thrust + F_gravity + F_drag
```

**In Body Frame (more complex due to rotating reference frame):**
```
m × (a_body + ω × v_body) = F_total_body
```

```python
# Simulate simple vertical motion (1D)
def simulate_vertical_motion(thrust, duration, dt=0.01):
    """
    Simulate vertical motion with constant thrust
    Returns time, position, velocity
    """
    m = 1.5  # kg
    g = 9.81  # m/s²

    # Drag coefficient (vertical)
    C_d_vertical = 0.1

    time = np.arange(0, duration, dt)
    position = np.zeros_like(time)
    velocity = np.zeros_like(time)

    for i in range(1, len(time)):
        # Forces
        F_thrust = thrust
        F_gravity = -m * g
        F_drag = -C_d_vertical * velocity[i-1] * abs(velocity[i-1])

        # Net force and acceleration
        F_net = F_thrust + F_gravity + F_drag
        acceleration = F_net / m

        # Update velocity and position (Euler integration)
        velocity[i] = velocity[i-1] + acceleration * dt
        position[i] = position[i-1] + velocity[i] * dt

    return time, position, velocity
```

### 5.2 Rotational Motion (Euler's Equation)

```
I × α + ω × (I × ω) = τ

Where:
I = inertia matrix
α = angular acceleration
ω = angular velocity
τ = applied torque
```

**Simplified (assuming I is diagonal and ω is small):**
```
I_x × α_x = τ_x  (roll)
I_y × α_y = τ_y  (pitch)
I_z × α_z = τ_z  (yaw)
```

```python
# Simulate roll motion
def simulate_roll(torque_roll, duration, dt=0.01):
    """
    Simulate roll motion with constant torque
    Returns time, roll angle, roll rate
    """
    I_x = 0.01  # kg·m² (roll inertia)
    damping = 0.05  # Aerodynamic damping

    time = np.arange(0, duration, dt)
    roll_angle = np.zeros_like(time)
    roll_rate = np.zeros_like(time)

    for i in range(1, len(time)):
        # Torques
        tau_applied = torque_roll
        tau_damping = -damping * roll_rate[i-1]

        # Net torque and angular acceleration
        tau_net = tau_applied + tau_damping
        alpha = tau_net / I_x

        # Update angular velocity and angle
        roll_rate[i] = roll_rate[i-1] + alpha * dt
        roll_angle[i] = roll_angle[i-1] + roll_rate[i] * dt

    return time, np.degrees(roll_angle), np.degrees(roll_rate)
```

## 6. Flight Modes Explained

### 6.1 Manual/Acro Mode

- Pilot directly controls angular rates
- No self-leveling
- Like flying a helicopter
- Most challenging but most responsive

**Control mapping:**
```
Stick input → Angular rate command
Roll stick right → Roll rate = 200°/s right
```

### 6.2 Angle/Stabilize Mode

- Pilot controls angles
- Quadcopter self-levels when sticks centered
- Easiest for beginners

**Control mapping:**
```
Stick input → Angle command
Roll stick right 50% → Target roll = 25°
```

```python
# Simulate angle mode control
def angle_mode_response(target_angle, Kp=5, Ki=0, Kd=0.5, duration=3, dt=0.01):
    """
    Simulate PID controller for angle stabilization
    """
    I_x = 0.01  # Inertia
    damping = 0.05

    time = np.arange(0, duration, dt)
    angle = np.zeros_like(time)
    rate = np.zeros_like(time)
    error_integral = 0

    for i in range(1, len(time)):
        # Error
        error = target_angle - np.degrees(angle[i-1])
        error_integral += error * dt
        error_derivative = -np.degrees(rate[i-1])  # Rate of change of error

        # PID control
        torque_command = Kp * error + Ki * error_integral + Kd * error_derivative

        # Limit torque
        torque_command = np.clip(torque_command, -0.5, 0.5)

        # Physics
        tau_damping = -damping * rate[i-1]
        tau_net = np.radians(torque_command) + tau_damping
        alpha = tau_net / I_x

        rate[i] = rate[i-1] + alpha * dt
        angle[i] = angle[i-1] + rate[i] * dt

    return time, np.degrees(angle), np.degrees(rate)
```

## 7. Stability and Control

### 7.1 Static vs Dynamic Stability

**Static Stability:** Tendency to return to equilibrium
**Dynamic Stability:** How it returns (oscillation/damping)

Quadcopters are **inherently unstable** - they require active stabilization!

```python
# Unstabilized vs stabilized
def simulate_unstabilized(initial_angle=5, duration=2):
    """Simulate quadcopter with no stabilization"""
    I_x = 0.01
    damping = 0.01  # Very little natural damping

    dt = 0.01
    time = np.arange(0, duration, dt)
    angle = np.zeros_like(time)
    rate = np.zeros_like(time)

    angle[0] = np.radians(initial_angle)

    for i in range(1, len(time)):
        # No control torque!
        # Small disturbance torque
        tau_disturbance = 0.01 * np.random.randn()
        tau_damping = -damping * rate[i-1]

        tau_net = tau_disturbance + tau_damping
        alpha = tau_net / I_x

        rate[i] = rate[i-1] + alpha * dt
        angle[i] = angle[i-1] + rate[i] * dt

    return time, np.degrees(angle)

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Unstabilized
t, angle_unstable = simulate_unstabilized()
axes[0].plot(t, angle_unstable)
axes[0].set_xlabel('Time (s)')
axes[0].set_ylabel('Roll Angle (°)')
axes[0].set_title('Without Stabilization (Unstable!)')
axes[0].grid(True)
axes[0].axhline(y=0, color='r', linestyle='--')

# Stabilized
t, angle_stable, _ = angle_mode_response(0, Kp=5, Kd=0.5, duration=2)
# Add initial disturbance
angle_stable += 5
axes[1].plot(t, angle_stable)
axes[1].set_xlabel('Time (s)')
axes[1].set_ylabel('Roll Angle (°)')
axes[1].set_title('With PID Stabilization (Stable)')
axes[1].grid(True)
axes[1].axhline(y=0, color='r', linestyle='--', label='Target')
axes[1].legend()

plt.tight_layout()
plt.savefig('stability_comparison.png')
```

### 7.2 Control Loop Hierarchy

**Typical quadcopter control architecture:**

```
Level 4: Navigation     (GPS waypoints)
           ↓
Level 3: Position       (X, Y, Z control)
           ↓
Level 2: Velocity       (Vx, Vy, Vz control)
           ↓
Level 1: Attitude       (Roll, Pitch, Yaw angles)
           ↓
Level 0: Rate           (Roll rate, Pitch rate, Yaw rate)
           ↓
        Motor Mixing
           ↓
        ESC/Motors
```

Each level commands the level below it!
